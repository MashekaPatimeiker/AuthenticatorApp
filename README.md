## 📱 О проекте

**Authenticator App** — это современное Android-приложение для двухфакторной аутентификации (2FA), написанное на Kotlin с использованием Jetpack Compose. Приложение генерирует TOTP-коды (Time-Based One-Time Password) для ваших аккаунтов, поддерживает сканирование QR-кодов и полностью работает офлайн.

### 🎯 Основные возможности

- ✅ **Генерация TOTP-кодов** — каждые 30 секунд обновляются 6-значные коды
- ✅ **QR-сканер** — добавление аккаунтов через сканирование QR-кода
- ✅ **Сохранение аккаунтов** — данные хранятся локально через DataStore
- ✅ **Удаление свайпом** — свайп влево для удаления с подтверждением
- ✅ **Информация об аккаунте** — свайп вправо для просмотра деталей
- ✅ **Генерация секретов** — автоматическая генерация случайных Base32 ключей
- ✅ **Валидация** — проверка корректности вводимых данных
- ✅ **Splash Screen** — стильный экран загрузки
- ✅ **Фиолетовая тема** — единый стиль Material 3
- ✅ **Плавные анимации** — переходы между экранами
